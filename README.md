# Omnibus Store

## Website

Open the live store: [https://oliverdillon2407-bot.github.io/website/](https://oliverdillon2407-bot.github.io/website/)

## Run locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser. In a Codespace, open or forward port 8000 from the **Ports** tab.
